# 2026-11-01 连续看图再次失效：IFEO 被清理 + 本体替换加固

## 现象（用户报告）
- 360zip 双击 webp 后，直接弹 2345 看图王，只显示单张，不能左右翻页。
- 用户原话：「360 zip 的连续看图又失效了，并且用的是 2345 的，你这个 bug 就没修复好。」

## 排查
1. Get-ItemProperty HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\2345PicViewer.exe
   → **键不存在**（10-31 装好的 IFEO 劫持被清掉了）。
   32 位视图 WOW6432Node 同样没有。
2. %TEMP%\ComicViewer.log 最后一条是 11-01 00:00:55 的 IFEO 剥离记录，之后再无任何记录
   → 从 00:00 以后 ComicViewer 一次都没被调起，与 IFEO 消失吻合。
3. 本机无 360 安全卫士/火绒等服务与驱动；D:\D\2345pic\2345PicViewer.exe 与 .real.exe
   同为 v10.9.1.9791（418,408B，sha256 6A6804D1…），2345 没升级过。
   → 清理者未能确定（未装 360 安全卫士；非 2345 升级覆盖）。按"清理工具会删 IFEO 项、但不会动文件本身"的通用行为，改走文件级劫持。

## 根因
IFEO（Image File Execution Options）是注册表实现，**可被系统清理/安全软件随时删除**，
一旦被删就退回 2345 直启单张。原方案单点依赖 IFEO，属于设计缺陷。

## 修复（双保险）
### A. 恢复 IFEO（原有的第二道）
ComicViewer.exe --install（实跑后确认写入 Debugger = "E:\360zip连续看图\ComicViewer.exe"）。
注意：--install 会弹出「安装结果」MessageBox，命令行会挂住，需手动关窗。

### B. 新增：本体替换（新主路径，不依赖注册表）
1. 备份 2345 原文件 → D:\D\2345pic\2345PicViewer.exe.orig-20261101（sha256 6A6804D1…）
   （.real.exe 本就是同一份副本，保留）
2. 把 E:\360zip连续看图\ComicViewer.exe 覆盖成 D:\D\2345pic\2345PicViewer.exe
3. 这样 360zip CreateProcess("D:\D\2345pic\2345PicViewer.exe", 图片) 时，
   启动的**文件本身就是 ComicViewer**，注册表被清也照样劫持。

### C. 配套修改（本次改的代码）
- src/ComicViewer.cs → Settings.ConfigPath：原来只认「exe 同目录的 ComicViewer.ini」。
  副本跑在 D:\D\2345pic\ 下时读不到配置 → original_viewer=null → 日志「Handoff: 找不到原看图器」。
  改为：exe 目录有 ini 就用；没有则回落到 E:\360zip连续看图\ComicViewer.ini（新增常量 MainDir）。
- ComicViewer.ini → original_viewer 由 D:\D\2345pic\2345PicViewer.exe 改为
  D:\D\2345pic\2345PicViewer.real.exe；否则副本模式下原看图器指向自己会被 IsSelf 拦掉。
  备份：ComicViewer.ini.bak-20261101。

## 验证（真实环境 = 用户这套安装，非干净环境）
模拟 360zip 的真实调用方式（CreateProcess 2345PicViewer.exe "<webp>"），两条路径分别测：

| 场景 | 日志 | 结果 |
|---|---|---|
| IFEO 在位 | IFEO 剥离: args[0]=D:\D\2345pic\2345PicViewer.exe -> 真实路径=…001.webp → Handoff: 启动 …2345PicViewer.real.exe | 进程 2345PicViewer.real PID 40228「看图王」起来 ✓ |
| IFEO 删除后（模拟被清理） | 普通启动: args=…001.webp → Handoff: 启动 …2345PicViewer.real.exe | 进程 2345PicViewer.real PID 37632「看图王」起来 ✓ |

编译后必须同步三处（本次已做）：
dist\ComicViewer.exe → ComicViewer.exe → D:\D\2345pic\2345PicViewer.exe

⚠️ 仍未做：完整「压缩包内铺图 83 张 + 翻页」需用户真实双击 360zip 里的 webp 复验
（本次只验证到「劫持→Handoff→拉起 .real.exe」这一步，铺图逻辑本次未改动）。

## 遗留风险
- 2345 看图王**升级**会重写 2345PicViewer.exe，本体替换失效 → 需重跑：
  Copy-Item E:\360zip连续看图\ComicViewer.exe D:\D\2345pic\2345PicViewer.exe -Force
  （IFEO 若还在则不受影响，两条路任一生效即可）
- 卸载/还原：Copy-Item D:\D\2345pic\2345PicViewer.exe.orig-20261101 D:\D\2345pic\2345PicViewer.exe -Force
  再 ComicViewer.exe --uninstall 移除 IFEO 与关联。
